# Sofo 🎹

- Sofo Github에 방문한 걸 환영해 ☺️
- Sofo는 찬양팀이 사용하는 악보에 관한 솔루션을 제공하는 서비스야.
- 우리는 **Sofo Score** 라는 악보 Form을 만들어 음악적인 소통의 효율성을 높이고 정확한 디렉팅을 위한 도구들을 제공해.
- Sofo를 통해 찬양팀 모두가 편하고 효율적인 소통을 하는 미래를 기대해줘!!
